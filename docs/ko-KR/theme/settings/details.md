# 설정과 화면 모드: 세부 사항

## 라이트 모드와 다크 모드 판정

| 모드 | 판정 |
| --- | --- |
| 시스템 `auto` | `prefers-color-scheme`을 읽으며, 시스템 설정이 바뀌면 페이지도 따라 바뀝니다. 브라우저가 시스템 설정을 알려 줄 수 없으면(이 미디어 쿼리를 지원하지 않거나, 라이트와 다크 어느 쪽도 일치하지 않으면) “시간에 따라” 모드로 처리합니다 |
| 라이트 `light` | 라이트 |
| 다크 `dark` | 다크 |
| 시간에 따라 `time` | 현지 시각이 07:00 이전이거나 18:59 이후이면 다크, 그 밖에는 라이트 |

“시간에 따라” 모드와, 브라우저가 시스템 설정을 알려 줄 수 없을 때의 “시스템” 모드에서는 테마가 1분마다 현재 시각을 읽고, 7:00이나 19:00이 지나면 자동으로 전환합니다. 그 밖의 경우에는 이 타이머가 실행되지 않습니다. 결과(`light` 또는 `dark`)는 `m3e-theme`의 `scheme` 속성과 `html.dark` 클래스에 기록됩니다.

## 첫 프레임 이전

`akariHead()`는 `<head>`에 작은 인라인 스크립트를 추가합니다. 이 스크립트는 `localStorage`에 저장된 모드를 읽어 위 표처럼 판정하고, 첫 프레임을 그리기 전에 `html.dark`를 설정하므로, 다크 페이지가 먼저 밝게 번쩍이는 일이 없습니다. 스크립트는 테마와 같은 `storageKey`와 기본 모드를 쓰므로, 둘 중 하나를 바꾸면 같은 값을 `akariHead()`에 전달하세요. 개발 서버는 페이지를 미리 렌더링하지 않으므로, 스크립트가 첫 프레임 전에 실행되는 것은 빌드 결과물에서뿐입니다.

## 전환 스낵바

화면 모드 버튼을 누를 때마다 화면 하단에 `m3e-snackbar`가 표시되고, 약 2.5초 후에 사라집니다. 다시 누르면 이전 스낵바가 새 스낵바로 바뀝니다. 텍스트는 UI 문자열 `schemeChanged`(“테마가 전환되었습니다: {mode}”)와 `schemeChangedFollowing`(“테마가 전환되었습니다: {mode} ({scheme})”)에서 가져옵니다. [국제화](/ko-KR/theme/i18n/api#messages)를 참고하세요.

## 각 옵션이 적용되는 곳

색상, 변형, 라이트 모드와 다크 모드, 대비, 모션은 앱 루트의 `m3e-theme`에 바인딩됩니다.

```vue
<m3e-theme
  :color="heroColor ?? settings.color"
  :variant="settings.variant"
  :scheme="resolvedScheme"
  :contrast="settings.contrast"
  :motion="settings.motion"
  strong-focus
>
  <!-- 앱 -->
</m3e-theme>
```

텍스트 방향과 글자 크기는 컴포넌트 속성을 거치지 않고, 문서의 루트 요소에 기록됩니다.

```ts
document.documentElement.dir =
  settings.direction === "auto" ? dir : settings.direction;
document.documentElement.style.fontSize = settings.textSize;
```

- `auto`(“언어에 따름”)는 현재 언어의 `dir`(`useData().dir`. 언어 구성의 값이며, 언어 구성에서 설정하지 않으면 언어 팩의 값)을 가져오며, 다른 언어로 전환하면 함께 바뀝니다. 따라서 아랍어처럼 오른쪽에서 왼쪽으로 쓰는 언어는 기본적으로 오른쪽에서 왼쪽입니다.
- 방향을 바꾸면 m3e 컴포넌트의 양방향 레이아웃과 아이콘 방향이 바뀌고, 병렬 페이지의 페이지 전환 애니메이션도 함께 좌우가 반전됩니다.
- 글자 크기를 바꾸면 `rem`으로 계산되는 모든 크기가 바뀝니다. 본문 텍스트, 제목, 간격, 코드 블록 등이 비례하여 커집니다. m3e 컴포넌트의 글자 크기는 컴포넌트 토큰으로 정해지므로 단순히 두 배가 되지는 않지만, 레이아웃은 문제없이 쓸 수 있는 상태를 유지합니다.
- 레이아웃은 `m3e-theme`이 생성한 팔레트를 루트 요소에 동기화합니다. `html`과 `body`, 앱 바, 내비게이션, 문서 표면, 목차, 모든 대화상자가 시드 색상, 변형, 라이트 모드와 다크 모드, 대비를 따릅니다. 별도의 고정 색상 세트는 없습니다.

## 읽기, 쓰기, 대체 동작

- 서버 렌더링은 기본값만 출력합니다. 하이드레이션 불일치를 피하기 위해 `localStorage`는 페이지가 브라우저에 마운트된 뒤에 읽습니다. 라이트 모드와 다크 모드는 위의 스크립트가 미리 적용합니다.
- 설정은 변경될 때마다 `localStorage`에 기록됩니다. 저장된 내용이 손상되었거나, 필드가 없거나, 값이 잘못되었으면 각 필드가 따로 기본값으로 돌아갑니다.
- 시크릿 모드나 저장 용량 초과로 읽기나 쓰기가 실패하면 오류를 조용히 무시하고, 페이지는 평소처럼 동작합니다.
- `persist: false`이면 설정은 현재 페이지에서만 유지되고, 새로 고치면 기본값으로 돌아갑니다.
- 브라우저, 도메인, 포트마다 `localStorage`가 따로 있습니다. 설정은 기기 간에 동기화되지 않으며, 저장소에 기록되지도 않습니다.

## 설정 대화상자

설정 대화상자는 검색, 언어 선택기와 같은 M3 컨테이너 변환을 씁니다. 버튼이 가운데 패널로 펼쳐지고, 패널 제목 앞의 톱니바퀴 아이콘이 바로 그 버튼입니다. 닫을 때는 같은 경로를 거꾸로 따라갑니다. 표현형 모션에서는 펼칠 때와 접을 때 모두 살짝 바운스가 있습니다. `Escape`, 스크림 클릭, 오른쪽 위의 닫기 버튼으로 닫을 수 있으며, 포커스는 대화상자를 연 버튼으로 돌아갑니다. 모션의 세부 사항은 [검색](/ko-KR/theme/search/details#container-transform)을 참고하세요. 창이 모든 옵션을 담기에 너무 낮으면(휴대폰, 높이가 낮은 창) 패널의 제목 아래 내용이 스크롤되며, 얇은 스크롤바가 표시됩니다.

- 색상은 네이티브 `<input type="color">`를 씁니다. 색상을 고르면 즉시 새 팔레트가 생성됩니다.
- 변형은 `m3e-filter-chip-set`(다중 선택 모양, 단일 선택 동작)을 씁니다. 대비, 모션, 방향, 글자 크기는 `m3e-segmented-button`을 씁니다.
- 설정 API는 `reset()`을 제공하지만, 공식 문서와 마찬가지로 인터페이스에는 “기본값으로 재설정” 버튼이 없습니다.
