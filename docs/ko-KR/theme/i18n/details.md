# 국제화: 세부 사항

## 페이지가 속하는 언어

경로가 언어를 결정합니다. 경로가 `/<language folder>/`로 시작하는 페이지는 그 언어에 속하고, 그 밖의 페이지는 모두 루트 언어에 속합니다. 소스에서는 루트 언어의 페이지도 자체 폴더(`docs/en-US/`)에 있지만, 폴더 이름 없이 제공됩니다. [페이지 작성: 세부 사항](/ko-KR/getting-started/writing/details#path-rules)을 참고하세요.

페이지가 최종적으로 갖는 구성은 공통 구성과 VitePress 로케일 구성 위에 해당 언어 폴더의 `config.ts`를 겹친 것입니다. [구성: 세부 사항](/ko-KR/getting-started/configuration/details#how-the-two-levels-layer)을 참고하세요.

## 언어 팩 선택

1. 선택 대상은 기본 제공 언어 팩 6개(`zh`, `en`, `ja`, `ko`, `fr`, `ar`)와 `languages`에 있는 언어 팩입니다. 기본 제공 언어 팩과 코드가 같은 언어 팩은 그 위에 겹쳐집니다.
2. 현재 언어의 `lang`을 소문자로 바꾸고(`_`는 `-`로 바꿉니다), 코드가 정확히 일치하는 언어 팩을 찾습니다.
3. 없으면 주 언어를 비교합니다. `zh-CN`과 `zh-TW`는 모두 중국어를, `en-GB`는 영어를, `fr-CA`는 프랑스어를 씁니다.
4. 그래도 없으면 영어를 씁니다.
5. 빈 곳을 채웁니다. 빠진 인터페이스 문자열은 영어로 표시되고, `fonts`가 없는 언어 팩은 테마의 글꼴을 쓰며, `dir`이 없는 언어 팩은 왼쪽에서 오른쪽입니다.
6. 언어 구성에 쓴 `messages`, `fonts`, `dir`, `markdown`을 언어 팩 위에 겹칩니다.

`settings.title`, `settings.labels`, `toc.overline`, `footer.message`, `search.placeholder`를 설정하지 않으면 이 값들도 이 표에서 가져오므로, 공통 구성 하나로도 모든 언어에서 적절한 기본값을 얻습니다. 공통 구성에 쓴 문자열은 모든 언어가 상속하므로, 언어마다 다른 문자열은 언어 구성에 씁니다.

## 언어 팩이 쓰이는 곳 {#where-language-packs-are-used}

- 빌드할 때 `akariContent`는 언어마다 VitePress 로케일을 생성합니다. `label`의 기본값은 `Intl.DisplayNames`로 얻은 그 언어로 표기한 언어 이름이며, 첫 글자는 대문자로 바뀝니다(예: `Français`). `dir`의 기본값은 언어 팩의 방향이고, `markdown`은 언어 팩의 Markdown 문자열 위에 언어 구성의 것을 겹친 값이며, `head`에는 그 언어의 글꼴 태그가 들어갑니다. VitePress는 로케일의 `markdown`으로 코드 블록 복사 버튼과 컨테이너 제목을 렌더링합니다.
- 페이지에서는 테마가 현재 언어의 인터페이스 문자열과 글꼴을 결정합니다. `useAkariConfig()`의 `messages`와 `fonts`입니다.
- 페이지에서 `lang` 속성으로 표시한 부분(언어 대화상자의 언어 이름 등)은 그 언어의 글꼴 스택을 씁니다. 이 규칙은 `fonts`가 있는 모든 언어 팩에서 생성되며, 스타일시트에는 특정 언어가 적혀 있지 않습니다.

## 언어 전환 시 이동하는 곳

1. 현재 경로를 대상 언어로 옮깁니다. `/getting-started/installation.html` → `/ko-KR/getting-started/installation.html`이며, 반대 방향으로는 접두사를 제거합니다.
2. 대상 언어의 내비게이션에 이 경로가 있으면 그 페이지를 엽니다. 내비게이션에는 병렬 페이지 그룹의 모든 페이지가 포함됩니다.
3. 없으면 대상 언어의 홈 페이지를 엽니다. 루트 언어는 `/`, 그 밖의 언어는 `/<language folder>/`입니다.

대상 언어의 내비게이션만 기준이 되므로, 내비게이션에 없는 페이지(예: 구조 밖의 페이지)는 전환 대상이 되지 않습니다.

## 언어 대화상자

- 언어 버튼은 둥근 외곽선 아이콘 버튼(`m3e-icon-button variant="outlined"`)입니다. 언어가 하나뿐이면 렌더링되지 않습니다.
- 대화상자는 검색 패널과 같은 컨테이너 변환을 씁니다. 버튼이 가운데 패널로 펼쳐지고, 패널 제목 앞의 아이콘이 바로 그 버튼이며, 닫으면 패널이 왔던 길로 돌아갑니다.
- 목록에서 각 언어는 두 줄을 차지합니다. 첫 줄에는 `label`이, 그 아래에는 `Intl.DisplayNames`로 얻은 현재 인터페이스 언어로 된 이름이 표시됩니다(한국어 인터페이스에서는 `zh-CN`이 “중국어(중국)”로 표시됩니다). 현재 언어는 체크 아이콘으로 강조됩니다. 검색 결과와 마찬가지로 목록의 첫 번째 항목만 위쪽 모서리가 둥글고, 마지막 항목만 아래쪽 모서리가 둥글습니다.
- 언어를 클릭하면 SPA 내비게이션으로 그 언어로 전환하고 대화상자를 닫습니다. `⌘`, `Ctrl` 등 보조 키를 누른 채 클릭하면 새 탭에서 엽니다.
- 열면 현재 언어에 포커스가 가고, `Tab`으로 언어 사이를 이동합니다. `Esc`, 스크림 클릭, 닫기 버튼으로 대화상자를 닫으며, 포커스는 언어 버튼으로 돌아갑니다.
- 좁은 화면에서는 버튼이 내비게이션 드로어 하단에 있고, 대화상자가 드로어를 덮습니다.

## 검색 범위

언어마다 자체 로컬 색인이 있고, 검색할 때는 현재 언어의 색인만 불러오므로 결과는 항상 현재 언어에서만 나옵니다. HTTP 백엔드와 등록된 백엔드는 현재 언어의 `lang`과 `locale`을 받으며, 검색 범위는 백엔드가 직접 정합니다. 검색 패널의 텍스트와 오류 메시지도 언어를 따릅니다.
