# 유체 배경 벽: 개요

`AkariFluidWall`은 WebGL2로 그리는 배경 패널입니다. 두 단계로 왜곡된 노이즈가 서로를 끌어당기는 장을 테마의 `--md-sys-color-*` 토큰만으로 색칠합니다. 배색과 밝기 전환을 따라가며, 위에 글을 올리거나 움직이는 바닥으로 그대로 둘 수 있습니다.

::: tip
멈춰 보이는 것은 정상입니다. `prefers-reduced-motion`이 켜져 있거나, 탭이 뒤에 있거나, 요소가 화면 밖에 있으면 그리기를 멈추고 돌아오면 다시 시작합니다.
:::

## 최소 사용법

```html
<AkariFluidWall />
```

아무 속성도 쓰지 않으면 `silk`입니다. 중간 정도의 주름, 꽃잎 같은 팔, 72px의 가는 격자, 포인터 빛, 높이는 `clamp(220px, 34vh, 380px)`.

## 변형

`variant`는 전체 형태를 고릅니다. 각각은 출발점 값의 묶음이고, 아래 표의 수치는 모두 덮어쓸 수 있습니다. `silk`에서 `scale`을 올려도 여전히 `silk`이며 더 잘게만 바뀝니다.

`silk`는 기본값입니다. 주름, 꽃잎, 격자가 모두 들어가 움직이는 비단에 가장 가깝습니다.

`aurora`는 노이즈 영역을 가로로 압축해 세로 커튼으로 만들고 더 빠른 빗살로 흘려보냅니다. 꽃잎과 격자는 없습니다.

`mesh`는 흐름을 거의 멈추고 부드러운 바탕 위에서 격자와 포인터 집광을 강하게 합니다. 글을 올리기에 가장 차분합니다.

`nebula`는 가장 잘고, 노이즈 축척이 크며 흐름이 아주 느리고 주변 어둡기가 강하며 벚꽃이 옅게 겹칩니다.

`blossom`은 `silk`의 주름을 약하게 하고 벚꽃 텍스처를 진하게 겹치며 격자를 그리지 않습니다.

## 겹쳐 놓는 텍스처

`texture`는 흐름 위에 정적인 무늬를 겹칩니다. 흐름과 독립이라 움직이지 않아 워터마크나 레이스 가장자리에 적합합니다.

`sakura`는 다섯 잎 꽃입니다. 밝은 쪽에서는 선화, 어두운 쪽에서는 채움입니다. `texture-tone`으로 고정할 수 있습니다.

`lace`는 타일이 아니라 띠를 하나씩 만듭니다. 양 끝은 화면 밖으로 빠지고 위치와 방향은 `seed`로 정해집니다. 생략하면 새로고침마다 달라지고, 고정하면 재현됩니다.

`vine`은 덩굴을 뻗으며 틀 밖으로 나갈 수도 있습니다.

::: tip
`variant` 없이 `texture="stars"`만 쓰면 `silk`의 겹침 투명도가 0이라 보이지 않습니다. `resolveFluid`가 `0.55`까지 올리므로 이름을 지정한 텍스처는 항상 보이며, `texture-opacity`로 낮출 수 있습니다.
:::

## 벽에 쓰기

기본 슬롯은 가운데 열입니다. `top`은 오른쪽 위, `bottom`은 왼쪽 아래에 고정됩니다. `placement`는 가운데 열을 가로로 옮깁니다.

슬롯에 내용이 있으면 글 아래에 베일이 옅게 깔려 가독성을 지킵니다. `placement`가 `start`, `center`, `end` 어느 쪽이어도 베일은 같은 방향으로 돕니다. 내용이 없으면 베일은 그려지지 않습니다.

## 틀을 넘는 덩굴

`texture="vine"`에서는 몇몇 덩굴이 패널 밖으로 뻗고, 몇몇은 앞쪽으로 판 안을 아치처럼 올라옵니다.

`popout`은 틀 밖으로 나가는 것을, `inward`는 판 안을 아치로 오르는 것을 허용하고, `safe-zone`은 피할 영역을 지정합니다.

`vine-colors`의 `base`는 개별 지정이 없는 모든 부위의 기본 색을 설정합니다. 각 부위(`fill`, `tint`, `halo`, `edge`, `fine`)에 색상과 투명도를 따로 지정할 수 있으며, 미지정 부위는 `texture-color`를 따릅니다.

## 배색 따라가기

색은 모두 `--md-sys-color-*`와 `--md-sys-motion-*`에서 옵니다. 앱 바의 배색 단추에 추가 설정이 필요 없습니다. 토큰은 `getComputedStyle` 문자열이 아니라 벽 안의 숨은 프로브로 읽으므로 `color-mix`나 `rgb(from …)` 같은 상대색도 정확히 풀립니다.

## GPU 감지

웹월은 WebGL 컨텍스트를 만들기 전에 `detect-gpu.js`의 `getGPUTier("BAD")`를 호출합니다. 감지는 페이지당 한 번만 실행됩니다.

결과는 `document.documentElement.dataset.akariGpuTier`에 저장됩니다. 결과가 `BAD`이면 WebGL2 컨텍스트와 덩굴 3D 장면을 만들지 않고 CSS 폴백 그라데이션만 표시합니다. `BAD`에는 WebGL2 미지원, SwiftShader 또는 llvmpipe 소프트웨어 렌더링 등이 포함됩니다.

디버깅을 위해 `[akari]`로 시작하는 경고와 감지 이유가 콘솔에 출력됩니다.

## 성능

- 셰이더는 필요할 때만 돕니다. 화면에 들어오면 시작하고, 나가거나 탭이 가려지면 멈춥니다. `prefers-reduced-motion: reduce`에서는 첫 프레임만 그립니다.
- 30fps 상한, DPR은 1.5까지, 화소 예산은 1.1M. 큰 캔버스는 줄여 그리고 CSS로 늘립니다.
- WebGL2가 없으면 CSS 그라디언트로 물러납니다. 색은 같고 움직임만 없습니다.
- 한 페이지에 여러 개를 두지 마세요. 각각 rAF 루프와 캔버스를 가집니다.

속성, 슬롯, CSS 클래스, 내보내는 기하 함수는 `API` 페이지에 있습니다.
