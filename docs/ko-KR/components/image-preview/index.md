# 이미지 미리보기

`AkariImagePreview` 는 이미지를 눌러서 여는 썸네일로 감쌉니다. 열면 본문 영역을 가득 채우고 확대·회전·이동이 가능하며, 키보드로도 같은 조작을 할 수 있습니다.

## 사용법

<AkariImagePreview src="/hero/theme-hero.svg" alt="테마 모습" label="테마 모습 보기">
  <img src="/hero/theme-hero.svg" alt="테마 모습" width="360" />
</AkariImagePreview>

```html
<AkariImagePreview src="/hero/theme-hero.svg" alt="테마 모습" label="테마 모습 보기">
  <img src="/hero/theme-hero.svg" alt="테마 모습" width="360" />
</AkariImagePreview>
```

기본 슬롯이 곧 썸네일입니다. 생략하면 컴포넌트가 `<img>` 를 직접 그리고, 넘기면 그 배치를 그대로 쓰며 바깥만 버튼으로 감쌉니다.

속성, 슬롯, CSS 클래스와 내보내는 기하 함수는 **API** 탭에 있습니다.

## 키보드

| 키 | 동작 |
| --- | --- |
| `Esc` | 미리보기 닫기 |
| `+`, `=` | 한 단계 확대 |
| `-`, `_` | 한 단계 축소 |
| `0` | 보기 초기화 |
| `r` | 시계 방향으로 90° 회전 |
| `Shift` + `r` | 반시계 방향으로 90° 회전 |

확대 범위는 50%–400% 이며 휠, 더블 클릭, 도구 모음 버튼으로 조작합니다. 누른 채 끌면 이동하고, 이미지를 더블 클릭하거나 도구 모음의 초기화 버튼을 누르면 처음 보기로 돌아갑니다.

## 동작과 대체

열 때는 썸네일 자리에서 그림이 넓어지고 닫을 때는 그 자리로 줄어듭니다. 보기를 확대·회전·이동한 뒤에는 돌아갈 상자가 하나가 아니므로 이 애니메이션을 건너뛰고 페이드만 합니다. “동작 줄이기”가 켜져 있으면 처음부터 페이드만 합니다.

썸네일이 로드되기 전까지 트리거는 비활성화되고 가운데에 로딩 볼을 표시합니다. 미리보기를 연 뒤에도 전체 이미지가 준비될 때까지 같은 볼이 나오며, 그동안 배경을 클릭해도 닫히지 않습니다(닫기 버튼과 `Esc`는 동작합니다). 두 막 모두 빌드 시점의 이미지 비율과 색을 사용하고, 이미지가 준비되면 MD3 시간·이징 토큰으로 페이드 아웃합니다.

미리보기 층은 `.akari-frame` 으로 텔레포트하므로 본문 배치나 `overflow` 에 잘리지 않습니다. 여는 동안 페이지 스크롤을 잠그고, 닫은 뒤에는 초점을 트리거 버튼으로 돌려 줍니다.
