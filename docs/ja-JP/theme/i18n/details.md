# 国際化：詳細

## ページがどの言語に属するか

言語はパスで決まります。パスが `/<言語フォルダー>/` で始まるページはその言語に属し、それ以外のページはすべてルート言語に属します。ソースでは、ルート言語のページも専用のフォルダー (`docs/en-US/`) に置かれますが、フォルダー名なしで配信されます。[ページの作成：詳細](/ja-JP/getting-started/writing/details#path-rules)を参照してください。

ページに最終的に適用される設定は、言語フォルダーの `config.ts` を、共通設定と VitePress のロケール設定の上に重ねたものです。[構成：詳細](/ja-JP/getting-started/configuration/details#how-the-two-levels-layer)を参照してください。

## 言語パックの選択

1. 選択の対象は、組み込みの 6 つの言語パック（`zh`、`en`、`ja`、`ko`、`fr`、`ar`）と `languages` にある言語パックです。組み込みの言語パックと同じコードを持つ言語パックは、その上に重ねられます。
2. 現在の言語の `lang` を小文字にし（`_` は `-` に変えます）、そのコードとちょうど一致する言語パックを探します。
3. なければ主言語で比べます。`zh-CN` と `zh-TW` はどちらも中国語、`en-GB` は英語、`fr-CA` はフランス語を使います。
4. それでもなければ英語を使います。
5. 足りない部分を補います。ないインターフェースの文字列は英語になり、`fonts` のない言語パックはテーマのフォントを、`dir` のない言語パックは左から右を使います。
6. 言語設定に書いた `messages`、`fonts`、`dir`、`markdown` が言語パックの上に重ねられます。

`settings.title`、`settings.labels`、`toc.overline`、`footer.message`、`search.placeholder` が設定されていない場合も、この表から取得されます。そのため、1 つの共通設定でもすべての言語で適切なデフォルトになります。共通設定に書いた文字列はすべての言語に引き継がれます。言語ごとに異なる文字列は言語設定に書きます。

## 言語パックが使われる場所 {#where-language-packs-are-used}

- ビルド時に、`akariContent` が言語ごとに VitePress のロケールを生成します。`label` のデフォルトは `Intl.DisplayNames` から得たその言語自身による呼び名で、先頭の文字は大文字になります（`Français` など）。`dir` のデフォルトは言語パックの文字の方向です。`markdown` は言語パックの Markdown の文字列に言語設定の値を重ねたもので、`head` にはその言語のフォントのタグが入ります。VitePress は、ロケールの `markdown` からコードブロックのコピーボタンとコンテナのタイトルを描画します。
- ページ内では、テーマが現在の言語のインターフェースの文字列とフォントを解決します。これが `useAkariConfig()` の `messages` と `fonts` です。
- `lang` 属性が付いたページの部分（言語ダイアログの言語名など）は、その言語のフォントスタックを使います。これらのルールは `fonts` を持つすべての言語パックから生成され、スタイルシートで特定の言語を指定している箇所はありません。

## 言語の切り替え先

1. 現在のパスを切り替え先の言語に移します。`/getting-started/installation.html` → `/zh-CN/getting-started/installation.html` のように変換し、逆方向ではプレフィックスを取り除きます。
2. 切り替え先の言語のナビゲーションにこのパスがあれば、それを開きます。ナビゲーションには並列ページのグループのすべてのページが含まれます。
3. なければ、切り替え先の言語のホームページを開きます。ルート言語では `/`、それ以外では `/<言語フォルダー>/` です。

判定に使うのは切り替え先の言語のナビゲーションだけなので、ナビゲーションにないページ（たとえばフォルダー構成の外にあるページ）が切り替え先になることはありません。

## 言語ダイアログ

- 言語ボタンは丸いアウトラインのアイコンボタン (`m3e-icon-button variant="outlined"`) です。言語が 1 つだけのときは描画されません。
- ダイアログは検索パネルと同じコンテナ変形を使います。ボタンが中央のパネルに展開し、パネルのタイトルの前にあるアイコンはボタンそのものです。閉じるときは、パネルが来た経路をたどって戻ります。
- 一覧では各言語が 2 行を使います。1 行目はその言語の `label`、その下は `Intl.DisplayNames` による現在のインターフェース言語での名前です（日本語のインターフェースでは、`zh-CN` は「中国語 (中国)」と表示されます）。現在の言語はチェックアイコン付きでハイライトされます。検索結果と同様に、角が丸くなるのは一覧の先頭の項目の上の角と、最後の項目の下の角だけです。
- 言語をクリックすると、その言語に切り替わってダイアログが閉じます。移動には SPA ナビゲーションを使います。`⌘`、`Ctrl` などの修飾キーを押しながらクリックすると、新しいタブで開きます。
- 開いたときは現在の言語にフォーカスがあり、`Tab` で言語の間を移動します。`Esc`、スクリムのクリック、閉じるボタンのいずれかでダイアログが閉じ、フォーカスは言語ボタンに戻ります。
- 狭い画面では、ボタンはナビゲーションドロワーの下部にあり、ダイアログはドロワーを覆って表示されます。

## 検索の範囲

言語ごとに独自のローカルインデックスがあり、検索では現在の言語のインデックスだけを読み込むので、結果は常に現在の言語のものだけです。HTTP バックエンドと登録したバックエンドは、現在の言語の `lang` と `locale` を受け取り、範囲は自分で決めます。検索パネルのテキストとエラーメッセージも言語に従います。
