# 検索

検索はアプリバーの右側にあります。広い画面ではプレースホルダーテキストとショートカットのヒントのある検索ボックスで、狭い画面では丸いボタンに縮みます。クリックするか `⌘K`（Windows と Linux では `Ctrl K`）を押すと、検索ボックスが検索パネルに展開します。

## 使い方

| キー | 操作 |
| --- | --- |
| `⌘K` / `Ctrl K` | どのページからでも検索を開く |
| `↑` / `↓` | 結果の間を移動する |
| `Enter` | 現在の結果を開く |
| `Esc` | 検索を閉じる |

結果はページとセクションごとに並び、それぞれに一致した部分の抜粋が付きます。セクションの結果を開くと、その見出しまでスクロールします。多言語のサイトでは、現在の言語のページだけが返されます。

## フローティング検索

`<SearchDock>` を、検索フィールドを着地させたい場所に置きます。タグはボックスを予約するだけで、実際のフィールドがアプリバーを離れてそのボックスを測り、ページを開いている間そこに留まります。

```md
# ガイド

<SearchDock variant="hero" align="center" placeholder="ガイドを検索" />
```

| プロパティ | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `placeholder` | `string` | `search.placeholder` | ここにドックしたときのプレースホルダー |
| `variant` | `"bar" \| "pill" \| "icon" \| "hero"` | `"bar"` | フィールドの外観 |
| `align` | `"start" \| "center" \| "end"` | `"start"` | アイコン、ラベル、ショートカットの位置 |
| `width` | `string \| number` | 外観の幅 | 予約ボックスの CSS 長さまたはピクセル幅 |
| `height` | `string \| number` | 外観の高さ | 予約ボックスの CSS 長さまたはピクセル高さ |
| `fill` | `boolean` | `false` | 外観の自然なサイズではなく親ボックスを埋める |
| `immersive` | `boolean` | `false` | ダイアログを開かず、その場で入力して検索します |
| `showShortcut` | `boolean` | `true` | ドック内のフィールドにショートカットのヒントを表示します |
| `background` | `string` | 外観の面色 | 検索面の CSS カラー |
| `borderColor` | `string` | 外観の枠線 | 検索面の枠線の CSS カラー |
| `shadow` | `boolean` | `true` | 浮遊影を残す。`false` で消す |
| `elevation` | `number` | 外観の標高 | 0〜5 の MD3 標高。`0` で影を消す |
| `priority` | `number` | `0` | 同じページの他のタグより優先する |

タグはグローバルに登録されているので、ページで import する必要はありません。フィールドを置きたいフローの中に書き、正確な位置は周囲のレイアウトに任せます。

このページを直接開くと、フィールドはトランジションなしでボックスに収まります。別のページから移動すると、アプリバーまたは直前のドックから飛び込みます。タグのないページへ移動すると、アプリバーへ飛び戻ってフェードアウトします。プロパティを変えると、その場で形や整列が変わります。同じページに複数のタグがある場合は `priority` が最も高いものが使われ、同じなら先に描画されたものが使われます。

フィールドがドックしている間、アプリバーのタイトルとドッキングしたタブが、空いたスロットを引き継ぎます。フィールドが戻るときにスロットがなめらかに開きます。タグは、ページ領域とビューポートの内側にあり、アプリバーとタブ列に重ならない場合だけフィールドを受け取ります。条件を満たさないときはフィールドはアプリバーに残り、スクロールしてタグが見える位置に来たときに飛び込みます。飛行中にスクロールすると、フィールドはタグに追従し、最後のフレームで位置が飛ぶことはありません。戻る途中でタグが再び使えるようになると、飛行は現在位置から反転し、最初からやり直しません。戻るときは、着地してからではなく飛行中にアプリバーの表面・文字・余白へ変化します。飛行とフェードはテーマの MD3 モーショントークンを使うため、「標準 / 表現力」の設定に従い、`prefers-reduced-motion` も尊重します。

すべてのプロパティは[ライブデモ](/ja-JP/theme/search/dock)と [API](/ja-JP/theme/search/api#searchdock) を参照してください。

## ローカルインデックス

デフォルトではバックエンドは不要です。テーマは、VitePress のローカル検索が作るインデックスを使います。インデックスは言語ごとに 1 つで、その言語で最初に検索するときにだけダウンロードされます。ページは見出しでセクションに分割され、照合は [MiniSearch](https://lucaong.github.io/minisearch/) が行います。中国語と日本語は単語に分割され、単語は途中までの入力でも一致し、長い単語は 1、2 文字の誤りがあっても一致します。開発サーバーの実行中は、インデックスが編集に追従します。

## 別の検索を使う

セマンティック検索、サイト外のコンテンツが必要なときは、HTTP エンドポイントや独自の JS 関数に切り替えます。

```ts
// docs/config.ts
search: {
  backend: { type: "http", endpoint: "/api/docs/search" },
},
```

バックエンドの書き方と結果の形式は [API](/ja-JP/theme/search/api) を、パネルのモーションとインデックスの構築・順位付けの仕組みは[詳細](/ja-JP/theme/search/details)を参照してください。
