# フローティング検索のデモ

このページは [`<SearchDock>`](/ja-JP/theme/search/api#searchdock) のライブデモです。タグは下の破線の着地ボックスにあり、検索フィールドはアプリバーを離れてそこへ着地します。

<SearchDockDemo />

試し方：

- このページを再読み込みする：フィールドはすでにボックス内にあり、飛び込みアニメーションはありません。
- このページを離れて（たとえば「概要」へ）から戻る：アプリバーからボックスへ飛び込みます。
- **外観**や**整列**を変える：フィールドがその場で形と整列を変えます。
- **ボックスを埋める**をオンにする：タグが外側のボックス全体（`width: 100%; height: 100%`）を占め、周囲のレイアウトのサイズに追従します。オフにすると外観の自然なサイズに戻ります。

ドック中もフィールドは操作できます。クリックするか `⌘K`（Windows / Linux では `Ctrl K`）を押すと、検索パネルがその位置から展開します。
