# 設定と外観：詳細

## ライトモードとダークモードの判定

| モード | 判定 |
| --- | --- |
| システム `auto` | `prefers-color-scheme` を読み取り、システムが切り替わるとページも追従します。ブラウザーがシステムの設定を取得できない場合（このメディアクエリに対応していない、またはライトとダークのどちらにも一致しない場合）は、時間帯として扱います |
| ライト `light` | ライト |
| ダーク `dark` | ダーク |
| 時間帯 `time` | 現地時刻が 07:00 より前、または 18:59 より後ならダーク、それ以外はライト |

時間帯モードと、ブラウザーがシステムの設定を取得できない場合のシステムモードでは、テーマが 1 分ごとに現在時刻を読み取り、7:00 または 19:00 を過ぎると自動で切り替えます。それ以外の場合、このタイマーは動きません。結果（`light` または `dark`）は、`m3e-theme` の `scheme` 属性と `html.dark` クラスに書き込まれます。

## 最初のフレームの前に

`akariHead()` は `<head>` に小さなインラインスクリプトを追加します。このスクリプトは `localStorage` に保存されたモードを読み取り、上の表のとおりに判定して、最初のフレームが描画される前に `html.dark` を設定します。そのため、ダークのページが一瞬ライトで表示されることはありません。スクリプトはテーマと同じ `storageKey` とデフォルトのモードを使うので、どちらかを変更したときは同じ値を `akariHead()` にも渡してください。開発サーバーはページをプリレンダリングしないため、スクリプトが最初のフレームより前に動くのはビルドの出力でだけです。

## 切り替えのスナックバー

カラーモードボタンを押すたびに、画面の下部に `m3e-snackbar` が表示され、約 2.5 秒後に消えます。もう一度押すと、古いスナックバーが新しいものに置き換わります。テキストはインターフェースの文字列 `schemeChanged`（「テーマを切り替えました：{mode}」）と `schemeChangedFollowing`（「テーマを切り替えました：{mode}（{scheme}）」）から取得されます。[国際化](/ja-JP/theme/i18n/api#messages)を参照してください。

## 各項目が適用される場所

カラー、バリアント、ライトモードとダークモード、コントラスト、モーションは、アプリのルートにある `m3e-theme` にバインドされます。

```vue
<m3e-theme
  :color="heroColor ?? settings.color"
  :variant="settings.variant"
  :scheme="resolvedScheme"
  :contrast="settings.contrast"
  :motion="settings.motion"
  strong-focus
>
  <!-- アプリ -->
</m3e-theme>
```

文字の方向と文字サイズはコンポーネントの属性を通さず、ドキュメントのルート要素に書き込まれます。

```ts
document.documentElement.dir =
  settings.direction === "auto" ? dir : settings.direction;
document.documentElement.style.fontSize = settings.textSize;
```

- `auto`（言語に合わせる）は現在の言語の `dir`（`useData().dir`。言語設定の値で、言語設定で指定していなければ言語パックの値）を使い、別の言語に切り替えるとそれに合わせて変わります。そのため、アラビア語のような右から左に書く言語は、デフォルトで右から左になります。
- 方向を切り替えると、m3e コンポーネントの双方向レイアウトとアイコンの向きに影響し、並列ページのページ切り替えのアニメーションもそれに合わせて反転します。
- 文字サイズを切り替えると、`rem` で計算されるすべてのサイズに影響します。本文、見出し、余白、コードブロックなどが比例して拡大・縮小します。m3e コンポーネントの文字サイズはコンポーネントのトークンで決まるため単純に 2 倍にはなりませんが、レイアウトは使える状態を保ちます。
- レイアウトは `m3e-theme` が生成したパレットをルート要素に同期します。`html` と `body`、アプリバー、ナビゲーション、ドキュメントサーフェス、目次、すべてのダイアログが、シードカラー、バリアント、ライトモードとダークモード、コントラストに従います。別に固定された色のセットはありません。

## 読み込み、書き込み、フォールバック

- サーバーレンダリングはデフォルト値だけを出力します。ハイドレーションの不一致を避けるため、`localStorage` はブラウザーでページがマウントされた後に読み取ります。ライトモードとダークモードは、上のスクリプトで先に適用されます。
- 設定は変更のたびに `localStorage` に書き込まれます。保存内容が壊れている、フィールドが欠けている、値が無効といった場合は、フィールドごとに個別にデフォルト値に戻ります。
- プライベートブラウズや容量の上限によって読み書きに失敗した場合、エラーは黙って無視され、ページは通常どおり動きます。
- `persist: false` の場合、設定は現在のページを開いている間だけ有効で、再読み込みするとデフォルト値に戻ります。
- `localStorage` はブラウザー、ドメイン、ポートごとに別々です。設定はデバイス間で同期されず、リポジトリに書き戻されることもありません。

## 設定ダイアログ

設定ダイアログは、検索や言語の選択と同じ M3 のコンテナ変形を使います。ボタンが中央のパネルに展開し、パネルのタイトルの前にある歯車アイコンはボタンそのものです。閉じるときは同じ経路を逆にたどります。エクスプレッシブなモーションでは、展開と折りたたみの両方に少しバウンドがあります。`Escape`、スクリムのクリック、右上の閉じるボタンのいずれかで閉じ、フォーカスは開いたボタンに戻ります。モーションの詳細は[検索](/ja-JP/theme/search/details#container-transform)を参照してください。ウィンドウの高さがすべてのオプションを表示するのに足りない場合（スマートフォンや高さの小さいウィンドウ）は、パネルのタイトルの下の内容がスクロールし、細いスクロールバーが表示されます。

- カラーにはネイティブの `<input type="color">` を使います。色を選ぶとすぐに新しいパレットが生成されます。
- バリアントには `m3e-filter-chip-set`（見た目は複数選択、動作は単一選択）を使います。コントラスト、モーション、方向、文字サイズには `m3e-segmented-button` を使います。
- 設定の API には `reset()` がありますが、インターフェースには「デフォルトに戻す」ボタンはありません。公式ドキュメントに合わせています。
