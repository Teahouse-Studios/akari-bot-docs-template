# 流動背景壁：概要

`AkariFluidWall` は WebGL2 で描く背景パネルです。二段の歪ませたノイズが互いを引っ張り合う場を、テーマの `--md-sys-color-*` トークンだけで彩色します。配色の切り替えにも明暗の切り替えにも追従し、上に文字を置くことも、動く床としてそのまま使うこともできます。

::: tip
止まって見えるのは仕様です。`prefers-reduced-motion` が有効なとき、タブが背面にあるとき、要素が表示領域の外にあるときは描画を止め、戻ると再開します。
:::

## 最小の使い方

```html
<AkariFluidWall />
```

属性を何も書かなければ `silk` です。中程度の皺、花びらのような腕、72px の細いグリッド、ポインタ光、高さは `clamp(220px, 34vh, 380px)`。

## バリエーション

`variant` は全体の形を選びます。どれも出発点の値の組で、下の表の数値はすべて上書きできます。`silk` の `scale` を上げても `silk` のままで、ただ細かくなります。

`silk` は既定値です。皺・花びら・グリッドがすべて入り、動く絹にもっとも近い見た目になります。

`aurora` はノイズの領域を横方向に圧縮して縦のカーテンにし、より速い櫛歯で流します。花びらとグリッドはありません。

`mesh` は流れをほぼ止め、柔らかい下地の上でグリッドとポインタの集光を強めます。文字を置く面としてはもっとも落ち着きます。

`nebula` はもっとも細かく、ノイズの尺度を大きく、流れを非常に遅く、周辺減光を強め、桜を薄く重ねます。

`blossom` は `silk` の皺を弱め、桜のテクスチャを濃く重ね、グリッドを描きません。

## 重ねるテクスチャ

`texture` は流れの上に静的な模様を重ねます。流れとは独立で動かないため、透かしやレースの縁に向いています。

`sakura` は五枚花びらです。明色では線画、暗色では塗りつぶしになります。`texture-tone` で固定できます。

`lace` はタイルではなく、帯を一本ずつ組み立てます。両端は画面の外へ抜け、位置と向きは `seed` で決まります。省略時は読み込みごとに変わり、固定すると再現できます。

`vine` は蔓を伸ばし、枠の外へ出ることもできます。

::: tip
`variant` を書かずに `texture="stars"` だけを指定すると、`silk` の重ね透明度が 0 のため見えません。`resolveFluid` が `0.55` まで持ち上げるので、名前を指定したテクスチャは必ず見えます。`texture-opacity` で下げられます。
:::

## 壁に書く

既定のスロットは中央の列です。`top` は右上、`bottom` は左下に固定されます。`placement` は中央の列を横に動かします。

スロットに内容があると、文字の下にベールが淡く敷かれ、可読性を保ちます。`placement` が `start`、`center`、`end` のどれであってもベールは同じ向きに回ります。内容がなければベールは描かれません。

## 枠を越える蔓

`texture="vine"` では、いくつかの蔓がパネルの外へ伸び、いくつかは手前へ向かって板の中を拱きます。

`popout` は枠の外へ出ることを、`inward` は板の中を拱くことを許し、`safe-zone` は避ける領域を指定します。

`vine-colors` の `base` は個別指定のない全部位のベース色を設定します。各部位（`fill`、`tint`、`halo`、`edge`、`fine`）にも個別の色と透明度を指定でき、未指定の部位は `texture-color` に従います。

## 配色への追従

色はすべて `--md-sys-color-*` と `--md-sys-motion-*` から来ます。アプリバーの配色ボタンに追加設定は要りません。トークンは `getComputedStyle` の文字列ではなく、壁の中の隠しプローブで読むため、`color-mix` や `rgb(from …)` のような相対色も正しく解決されます。

## GPU 検出

WebGL コンテキストを作る前に、ウォールは `detect-gpu.js` の `getGPUTier("BAD")` を呼び出します。検出はページごとに一度だけです。

結果は `document.documentElement.dataset.akariGpuTier` に保存されます。`BAD` の場合は WebGL2 コンテキストも藤の 3D シーンも作成せず、CSS のフォールバックグラデーションだけを表示します。`BAD` には WebGL2 非対応、SwiftShader または llvmpipe のソフトウェア描画などが含まれます。

デバッグ用に `[akari]` で始まる警告と検出理由がコンソールに出ます。

## 性能

- シェーダは必要になったときだけ動きます。表示領域に入れば開始し、外れるかタブが隠れれば止まります。`prefers-reduced-motion: reduce` では最初のフレームだけ描きます。
- 30fps 上限、DPR は 1.5 まで、画素予算は 1.1M。大きなキャンバスは縮小し、CSS で引き伸ばします。
- WebGL2 がなければ CSS のグラデーションに退避します。色は同じで、動きだけがありません。
- 一つのページに何枚も置かないでください。それぞれに rAF ループとキャンバスがあります。

属性・スロット・CSS クラス・エクスポートされる幾何関数は「API」ページにあります。
