# 搜索：技术细节

## 容器变换

搜索面板是原生的模态 `<dialog>`，用 Web Animations API 以 M3 容器变换展开。语言选择与设置模态框使用同一套实现（`useContainerTransform`）。

- 动画的对象始终是真实的面板，它从第一帧起就按最终尺寸排版。开始时只通过一个与按钮同形的窗口（`clip-path` 胶囊）露出面板自己搜索栏的起始端，并用位移把这个窗口放到按钮上，所以第一帧看到的仍是「图标 + 占位文字」的搜索框。
- 展开时位移归零，窗口扩大到整个面板（包括阴影），内容随之逐步显露，结果区与关闭按钮同时淡入，中途不会出现空白的表面。动画结束时的状态就是面板的静止样式，移除动画不会跳变。
- 按钮的一份像素副本叠在窗口上随之移动。按钮与面板的内容不交叉叠化，而是先后淡出淡入（M3 的 fade through）：打开时面板表面先在副本下方淡入，副本随后淡出，面板自己的搜索栏再淡入，两种大小不同的文字不会同时出现。
- 关闭时原路收回：结果区与搜索栏先淡出，按钮副本在途中淡入接替，面板表面随后在它下方淡出。落回按钮的最后一段，包括表现力动效的回弹，看到的都是按钮本身，结束时与真实按钮完全一致；没有底色的按钮（例如齿轮按钮）因此也不会在结束时闪出一块底色。打开或关闭途中被打断时，从当前帧继续反向运动。
- 窗口的尺寸与圆角取自按钮当前的位置与大小，面板位置在动画开始时重新测量，不依赖固定坐标。

| 动效 | 展开 | 收回 |
| --- | --- | --- |
| 标准 | 约 300ms，`cubic-bezier(0.2, 0, 0, 1)` | 约 250ms，不回弹 |
| 表现力 | 约 500ms，`cubic-bezier(0.38, 1.21, 0.22, 1)`，略微越过后回稳 | 约 400ms，同样的曲线，收回时带一点回弹 |

系统开启「减少动态效果」时直接显示与关闭。原生 dialog 提供顶层显示、背景 inert 与 `Esc` 关闭；打开时焦点进入输入框，关闭后回到打开前的焦点，没有可用焦点时回到搜索按钮。

## 索引的生成

- 索引由 VitePress 的本地搜索生成：它用站点的 Markdown 渲染器渲染每一页，按带锚点的标题把页面切成章节，每种语言一个索引，构建时各打包成一个文件。开发服务器运行时，页面修改后索引随之更新并推送到浏览器。
- 地址与锚点取自渲染结果，与页面实际的地址和标题 id 一致，包括 rewrites 后的地址与 `{#锚点}` 写法。
- 正文是渲染后的 HTML 去掉标签，代码块中的文字也在内，所以代码中的名称同样可以搜到。头部信息中写了 `search: false` 的页面不进入索引。
- 中文与日文没有空格，切词使用 `Intl.Segmenter`；主题查询时使用同样的切词方法（`tokenizeSearchText`），查询与索引中的词一致。

## 匹配与排序

查询按与索引相同的方法切成词，由 MiniSearch 匹配：

- 词可以完全相同，也可以只是一个更长的词的开头；较长的词允许拼错，编辑距离不超过词长的 20%。
- 每个词都要命中；一条结果都没有时，退而接受命中任意一个词的章节。
- 相关度按 BM25 计算，章节标题的权重为 4，正文为 2，上级标题为 1。

结果再按照查询的原文分层排序，表中的「标题」是章节自己的标题：

| 层级 | 条件 |
| --- | --- |
| 4 | 标题与整个查询完全相同 |
| 3 | 标题以整个查询开头 |
| 2 | 标题包含整个查询 |
| 1 | 上级标题或正文中逐字出现整个查询，例如中文短语 |
| 0 | 其他 |

层级高的在前；在第 4、3 层中，页面排在它的章节之前；同层的按 MiniSearch 的相关度，再按标题排序。同一地址只保留一条，最多返回 `maxResults` 条。结果带有命中的词（`terms`），包括只输入了开头或拼错的词，面板据此高亮。

每种语言有自己的索引，结果自然只来自当前语言。

## 加载与缓存

- 每种语言的索引在这种语言第一次搜索时加载，之后在页面中缓存；开发时索引更新后缓存随之清空。
- 输入有 `debounce` 的防抖；输入新查询或关闭面板时，进行中的请求通过 `AbortSignal` 中止。
- 索引加载失败或格式错误时，面板显示错误与重试按钮。

## 面板的状态

| 状态 | 显示 |
| --- | --- |
| 空输入 | 搜索提示与快捷键说明 |
| 加载中 | M3 加载指示器 |
| 有结果 | 页面标题、章节标题、摘要与命中高亮；当前项使用 `secondary-container` 底色。列表是一个整体：只有首项的上边与末项的下边是圆角，中间各项是直角 |
| 无结果 | 提示换一个关键词 |
| 失败 | 错误原因与重试按钮 |

结果跳转使用 VitePress 的路由，保持 SPA 导航。输入框、结果列表与错误提示都有对应的 ARIA 名称。顶栏的快捷键提示使用 `label-small` 字体与全圆角的键帽；面板中的方向键、`Enter` 与 `Esc` 提示使用 `shape-extra-small` 圆角。

## 已知限制

- 本地搜索按词匹配，没有语义搜索与同义词；需要时接入 HTTP 或注册的后端。中文、日文的切词取决于浏览器的 `Intl.Segmenter`，不支持它的浏览器只能按空格与标点切分。
- 本地索引只在开发服务器运行或构建时生成；开发服务器没有运行时直接修改的 Markdown，要等下一次 `npm run dev` 或 `npm run build` 才能搜到。
