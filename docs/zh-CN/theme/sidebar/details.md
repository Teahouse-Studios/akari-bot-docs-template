# 侧边导航：技术细节

## rail 与导航抽屉

- **rail**：独占页面左侧整高的条状区域，顶栏从它右侧开始。`m3e-nav-rail` 中每个分类是一个 `m3e-nav-item`；带子项的分类指向它的第一个页面，没有子项的顶层项直接作为链接。右侧的分隔线只在旁边显示导航抽屉时出现。
- **抽屉的内容**：用 `m3e-nav-menu` 列出分类中的页面。分类名称已经显示在 rail 上，抽屉中不重复；抽屉中的项只显示文字，徽标与嵌套分组保留。
- **1600px 及以上**：当前页面属于某个分类时，抽屉常驻在 rail 右侧，挤占内容宽度。是否常驻由当前路由与 CSS 媒体查询共同决定，服务端渲染与首屏就是最终状态，刷新时不播放展开动画；之后窗口变宽或从没有子菜单的页面进入分类时，宽度以不回弹的弹簧从 0 展开，减速停在抽屉宽度，内容区随之让出空间；反向收起时同样减速收到 0，内容区随之收回空间。悬停其他分类时，当前列表先淡出，再淡入该分类；指针离开导航区域后恢复当前分类。
- **960–1599px**：指针在分类上停留约 100ms 后，抽屉从 rail 下方滑出，占满页面整高，覆盖在顶栏与内容之上（3 级阴影，指针移入抽屉时 5 级；末端 16px 圆角）。在分类之间移动时列表先淡出再淡入。指针离开 rail 与抽屉约 200ms 后滑回。
- **960px 以下**：rail 与抽屉隐藏，顶栏菜单按钮打开全量导航抽屉。一级菜单与 rail 对应并显示相同的图标，子项只显示文字。抽屉顶部紧贴顶栏、没有圆角，底部末端 16px 圆角。
- **点击**：鼠标点击分类跳转到它的第一个页面，带修饰键点击交给浏览器在新标签页打开。触屏没有悬停，点击分类改为打开或关闭抽屉，点击外部关闭。抽屉中的链接走 VitePress 的 SPA 导航，点击后抽屉收起。
- **分组**：读者手动展开或收起的分组，在抽屉切换到其他分类再回来后保持原样，整页刷新后才回到默认状态；进入某个分组中的页面时，这个分组展开。抽屉显示一个分类的列表时，分组直接处于这个状态，不播放展开动画；只有读者点击分组，或进入收起的分组中的页面时，展开与收起才有动画。

所有过渡都使用 `m3e-theme` 提供的 M3 Expressive 动效令牌（`--md-sys-motion-spring-*`），随设置中的「动效」在标准与表现力之间切换；系统开启「减少动态效果」时直接切换。

## 当前页面的判断

- 路由比较忽略 `base`、末尾斜杠、查询参数与 hash，并把 `.html` 视为同一路径：`/guide/intro/`、`/guide/intro.html` 与 `/guide/intro?from=nav` 都对应同一项。外部链接与只有锚点的链接不会成为当前项。
- 找到当前项后，它的祖先分组都获得 `open`，它自己获得 `selected`；`m3e-nav-menu-item` 把 `selected` 映射为 `aria-current`。平行页面组在组内任何一页上都是选中状态。
- 写成对象的导航先按路径长度从长到短排序，取第一个匹配当前路径的键。

## 上一页与下一页

正文末尾的翻页卡片只出现在平行页面中，在同一组的各页之间翻页：取当前页面在组内的前一页与后一页，卡片上的标题是它们的标签名。组内第一页没有上一页，最后一页没有下一页；不在组中的页面不显示翻页卡片，所以翻页不会把读者带到另一篇文档。页尾的链接分栏取自整棵导航树，平行页面组在其中合为一项。

## 平行页面的标签栏

### 位置与外观

- 组内每一页的表面顶部都有一条标签栏，左右边距与头图相同；有头图时头图排在它下方，所以组内各页的标签栏位置一致。
- 每个标签是普通链接，点击走 SPA 导航，当前页带 `aria-current="page"`，由 `secondary-container` 底色的指示器标出。点击后指示器立即滑向新标签，不等新页面加载完成；滑向首尾两个标签时用不回弹的曲线，避免越过圆角的末端。
- 标签栏是带名称的 `<nav>` 地标，例如「图标页面」。任何时候只有一份标签栏对辅助技术可见，飞行中的副本也不可聚焦。
- 点击当前页的标签不做任何事，不会回到页面顶部。

### 横向滚动

窗口窄到放不下全部标签时，标签保持宽度，标签栏可以横向滑动，底部出现一条 4px 的细滚动条。读者自己滚动之前，它会自动滚到让当前标签完整显示的位置，切页与窗口宽度变化时重新对齐；读者用滚轮、拖动、触摸或方向键滚动过之后不再干预，直到下一次切页。只有标签本身的宽度超出时才允许滚动，指示器的动画越过末端不会让它出现滚动条。

### 收进顶栏

- 向下滚动、标签栏离顶栏不到 24px 时，它缩成 40px 高的紧凑标签栏，铺满顶栏标题与右侧第一个按钮之间的空白，两侧各隔 `--akari-app-bar-tabs-gap`；它原来的位置重新离开顶栏 24px 以上时，再回到页面中。
- 两个位置之间，标签栏的一份副本移动过去，位置、尺寸、字号与底色同时过渡。水平与竖直方向各由一个 M3 默认空间弹簧驱动：表现力动效阻尼比 0.8、刚度 380，标准动效 0.9、700。弹簧从静止起步，表现力动效收尾带一点回弹。
- 两个方向先后起步、部分重叠：收进时，副本先在顶栏下方收窄，收到空白处放得下的宽度时正好升过顶栏下沿；回到页面时，先以紧凑宽度落下，离开顶栏后再展开。第二个方向的起步时间由两个弹簧的轨迹算出，副本在顶栏范围内始终在空白处之内，不会经过标题与搜索框，也不会被切开。
- 副本的落点每帧重新测量，页面仍在滚动时也能落准；动画中途改变滚动方向，副本从当前位置折返。
- 快速滚动时标签栏若已部分滑进顶栏下沿，副本先从顶栏下沿露出、退到顶栏下方，再按上面的顺序收进去。标签栏所在的表面整个滚出视口后才跳回来时（例如从页尾跳到锚点），没有可以飞行的起点，顶栏中的标签栏直接淡入。

### 与标题分享空间

- 主题按未截断的宽度测量顶栏标题（站点名称，或换成的页面标题），标题变化、窗口缩放与字体加载后都重新计算。
- 收进顶栏时，先给标签栏留出它的内容宽度与两侧间距，标题最多使用剩下的宽度，更长的部分以省略号截断，标签栏再铺满其余空间。
- 标签栏收在顶栏期间，标题宽度的变化（站点名称与页面标题互换、切到标题长度不同的另一页）都平滑过渡，标签栏随之伸缩；过渡中的标题直接裁切而不显示省略号，结束后再显示。宽度相差不到 2px 时不重新过渡。

### 固定在顶栏下方

- 标题至少要保留 logo、版本号与约六个字（更短的标题保留全部）才收进顶栏。站点名称与页面标题都要满足，因为收进顶栏后两者都可能显示；所以是否收进只取决于窗口宽度，不会在滚动时随顶栏换显标题而来回变化。
- 不满足时，标签栏滚到顶栏下方就停在那里，以 2 级阴影轻微抬起，浮在滚过的正文之上，四周的正文照常可见、可以点击；吸附与离开时阴影淡入淡出。此时 `html` 带 `akari-tabs-pinned` 类，锚点跳转与目录的吸附位置都会让开它，文章标题滚到它后面时顶栏同样换显页面标题。
- 窗口变宽、顶栏放得下时，标签栏从顶栏下方飞进顶栏；变窄、放不下时同样飞到顶栏下方：副本从它在顶栏中还露出的那一段出发（完全被挤没时从空白处所在的位置以零宽度出发），先落到顶栏下方，再展开，途中不会被压窄。
- 拖动窗口时，搜索框与按钮的宽度还在过渡，顶栏的空间不是最终值，所以要等它稳定约 200ms 再决定是否收进；只有顶栏中的标签栏已经放不下、会被截断时才立即退出。
- 正文与头图各自单独层叠，其中的内容（例如代码块的复制按钮）滚到固定的标签栏下面时不会浮到它上面。

## 切页动画

在组内切换页面时，文档表面保持不动，只有内容沿标签的方向左右移动（M3 的 shared axis X）：切到右侧的标签时，当前内容向左淡出、新内容从右侧 30px 处滑入，反方向相反；从右到左的排版下方向随之镜像。标签栏本身不参与移动：

- 标签栏收在顶栏或固定在顶栏下方时，切页后它仍留在原处，新页面直接定位到正文开始处，文章标题（头图或开头的一级标题）已滚到顶栏（或固定的标签栏）下方，顶栏显示新页面的标题。新页面不够长、滚不到那里时，标签栏回到页面中。链接带锚点时以锚点为准；浏览器前进、后退时恢复原来的滚动位置。
- 标签栏在页面中时，新页面照常从顶部开始，标签栏留在原处；切换前页面已向下滚动了一点时，标签栏平滑回到顶部的位置。

离开这组页面时，整个表面照常淡出淡入。系统开启「减少动态效果」时，标签栏与内容都直接切换。

## 无障碍

- `m3e-nav-menu` 根元素带 `aria-label`（「文档导航」），是页面的主导航地标；rail 有自己的名称（「文档分类」）。
- rail 支持方向键在分类间移动焦点，分类项带 `aria-haspopup`、`aria-expanded` 与 `aria-controls`。960–1599px 时按 `Enter` 或空格打开抽屉并把焦点交给菜单，`Escape` 关闭并把焦点还给分类；1600px 以上时，对当前分类按 `Enter` 直接聚焦常驻抽屉。
- 收起的抽屉带 `inert`，不进入 Tab 顺序与无障碍树。
- 图标对辅助技术隐藏，名称由 `label` 插槽中的文字承担。自定义导航时应保留「菜单根元素 + 标签中的链接 + `selected` 状态」的结构，不要用 `div` 模拟链接。
