# التنقل الجانبي

على سطح المكتب، يسرد شريط التنقل (rail) بعرض 96px على اليمين الفئات، ويسرد درج التنقل صفحات الفئة الحالية. وعندما تكون النافذة أضيق من 960px، يفتح زر القائمة في شريط التطبيق درج تنقل يضم كل الصفحات.

## شريط التنقل ودرج التنقل

- **شريط التنقل**: أيقونة واحدة لكل فئة. تظهر فئة الصفحة الحالية محدّدة، وتصبح أيقونتها ممتلئة. النقر على فئة يفتح صفحتها الأولى. في أسفل شريط التنقل يوجد زر المظهر، إضافةً إلى زر اللغة عندما يحتوي الموقع على عدة لغات.
- **درج التنقل**: عندما يكون عرض النافذة 1600px أو أكثر، يبقى مفتوحًا على يسار شريط التنقل. وبين 960 و1599px، ينزلق للخارج من تحت شريط التنقل عندما يستقر المؤشر على فئة، وينزلق عائدًا عندما يغادر المؤشر. على الشاشات اللمسية، يفتحه النقر على فئة أو يغلقه.
- **الشاشات الضيقة**: يُخفى شريط التنقل والدرج. يفتح زر القائمة درج التنقل الكامل، الذي تطابق قائمته العليا الفئات الموجودة في شريط التنقل. ويقع زرّا المظهر واللغة في أسفل الدرج.

## مصدر التنقل

يُولَّد التنقل من المجلدات الموجودة في مجلد اللغة: كل مجلد فئة هو فئة في شريط التنقل، ومجلدات المقالات داخل الفئة هي صفحاتها. تُضبط الأسماء والأيقونات والترتيب في البيانات الأمامية (frontmatter) لكل مقالة. راجع [كتابة الصفحات](/ar-SA/getting-started/writing).

توضع أسماء الفئات وأيقوناتها في `sidebar.categories` ضمن التهيئة:

```ts
// docs/config.ts
sidebar: {
  categories: {
    "getting-started": { icon: "rocket_launch" },
    theme: { icon: "palette" },
  },
},

// docs/ar-SA/config.ts
sidebar: {
  categories: {
    "getting-started": { text: "البدء" },
    theme: { text: "السمة" },
  },
},
```

يمكنك أيضًا كتابة التنقل كله يدويًا باستخدام `sidebar.items` في التهيئة. راجع [API](/ar-SA/theme/sidebar/api#navigation-written-by-hand).

## الصفحات المتوازية {#parallel-pages}

يمكن تقسيم المقالة إلى عدة صفحات، كما تُقسَّم صفحة الأيقونات في [m3.material.io](https://m3.material.io/styles/icons) إلى Overview وGuidelines وSpecs. تشغل الصفحات مدخلًا واحدًا في الشريط الجانبي، ويبدّل شريط تبويب في أعلى الصفحة بينها.

- عند التمرير إلى الأسفل، يتقلص شريط التبويب ويطير إلى المساحة الفارغة على يسار عنوان شريط التطبيق. وعند التمرير إلى الخلف يعود إلى الصفحة.
- عندما لا يتسع له شريط التطبيق، يبقى شريط التبويب أسفل شريط التطبيق بدلًا من ذلك، مع ظل خفيف.
- عند التبديل بين صفحات المجموعة، ينزلق المحتوى يسارًا أو يمينًا. إذا كان شريط التبويب مستقرًا في شريط التطبيق، يبقى في مكانه، وتبدأ الصفحة الجديدة مباشرةً عند نص المتن.
- تبقى بطاقتا الصفحة السابقة والصفحة التالية في نهاية المحتوى داخل المجموعة: فالصفحة الأولى فيها بلا صفحة سابقة، والأخيرة بلا صفحة تالية.

صفحات [الأيقونات](/ar-SA/styles/icons) وكل مستندات السمة في هذا الموقع منظّمة بهذه الطريقة. راجع [كتابة الصفحات](/ar-SA/getting-started/writing#parallel-pages).

لكل حقل، راجع [API](/ar-SA/theme/sidebar/api). ولمعرفة متى يُفتح الدرج، وكيف يطير شريط التبويب وغير ذلك، راجع [التفاصيل](/ar-SA/theme/sidebar/details).
