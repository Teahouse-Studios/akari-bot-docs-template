# التنقل الجانبي: API

## البيانات الأمامية للمقالة

| الحقل | النوع | الوصف |
| --- | --- | --- |
| `title` | `string` | الاسم في التنقل؛ افتراضيًا أول h1، ثم اسم المجلد |
| `icon` | `string` | أيقونة عنصر التنقل |
| `badge` | `string` | شارة عنصر التنقل |
| `order` | `number` | الموضع داخل الفئة، والأصغر أولًا؛ والصفحات التي لا تحمله تأتي في الأخير، مرتّبة بحسب اسم المجلد |
| `parallel` | `string[]` | الصفحات المتوازية في المجلد نفسه |
| `tab` | `string` | العنوان في شريط التبويب؛ افتراضيًا عنوان الصفحة |
| `category` | `string` | للصفحة الرئيسية للغة فقط: الفئة التي تنضم إليها |

لكل حقول البيانات الأمامية (frontmatter)، راجع [كتابة الصفحات](/ar-SA/getting-started/writing/api#frontmatter).

## sidebar

| الحقل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `categories` | `Record<string, AkariSidebarCategory>` | لا شيء | الفئات للتنقل المولَّد من المجلدات. المفاتيح هي أسماء مجلدات الفئات؛ وترتيبها هو الترتيب في شريط التنقل |
| `items` | `AkariSidebarItem[] \| Record<string, AkariSidebarItem[]>` | لا شيء | تنقل مكتوب يدويًا؛ عند ضبطه لا يعود التنقل يُولَّد من المجلدات |
| `width` | `number` | `320` | العرض المرجعي لدرج التنقل، محصور بين 240 و400 |

حقول `AkariSidebarCategory`:

| الحقل | النوع | الوصف |
| --- | --- | --- |
| `text` | `string` | اسم الفئة؛ افتراضيًا اسم المجلد |
| `icon` | `string` | الأيقونة في شريط التنقل؛ افتراضيًا `category` |
| `collapsed` | `boolean` | عند `false` تكون الفئة موسّعة افتراضيًا في درج الأجهزة المحمولة؛ وتُفتح عند الانتقال إلى صفحة فيها، وتبقى على الحال التي تركها القارئ عليها بعد فتحها أو إغلاقها |

عرض درج التنقل على سطح المكتب هو `max(240px, width - 96px)`: أي 240px افتراضيًا، و304px عندما يبلغ `width` حده الأقصى 400. أما درج الأجهزة المحمولة فيستخدم `width` مباشرةً.

## التنقل المكتوب يدويًا {#navigation-written-by-hand}

`sidebar.items` قائمة من `AkariSidebarItem`. وللتنقل المولَّد من المجلدات البنية نفسها.

| الحقل | النوع | الوصف |
| --- | --- | --- |
| `text` | `string` | مطلوب. النص المعروض |
| `link` | `string` | العنوان المستهدف؛ وتبدأ العناوين داخل الموقع بـ `/` |
| `icon` | `string` | اسم أيقونة مسجّلة. تعرضها العناصر العليا في شريط التنقل وفي القائمة العليا لدرج الأجهزة المحمولة؛ افتراضيًا `category` |
| `badge` | `string` | الشارة. في العنصر العلوي تظهر في أعلى يسار أيقونة شريط التنقل؛ وفي العنصر الفرعي تظهر في الدرج |
| `collapsed` | `boolean` | عند `false` تكون المجموعة موسّعة افتراضيًا؛ وتُفتح عند الانتقال إلى صفحة فيها؛ والمجموعة التي فتحها القارئ أو أغلقها تبقى على حالها عندما يتبدل الدرج إلى فئة أخرى ثم يعود |
| `items` | `AkariSidebarItem[]` | العناصر الفرعية، متداخلة إلى أي عمق |
| `tabs` | `AkariSidebarItem[]` | الصفحات المتوازية: تصبح صفحات المجموعة عنصرًا واحدًا في الشريط الجانبي يرتبط بالصفحة الأولى، ويظهر شريط تبويب في أعلى الصفحة |

```ts
sidebar: {
  items: [
    {
      text: "الأنماط",
      icon: "style",
      items: [
        { text: "الألوان", link: "/styles/color" },
        {
          text: "الأيقونات",
          tabs: [
            { text: "نظرة عامة", link: "/styles/icons" },
            { text: "اختيار الأيقونات", link: "/styles/icons/choosing" },
            { text: "استخدام الأيقونات", link: "/styles/icons/using" },
          ],
        },
      ],
    },
  ],
},
```

يمكن أن تكون `items` كائنًا أيضًا: المفاتيح بادئات مسارات، والقيم هي التنقل المعروض تحت تلك المسارات. وتفوز أطول بادئة للمسار الحالي (`/theme/settings` تتقدم على `/theme/`، و`/` تطابق كل المسارات).

لا يصبح تبويبًا من عناصر `tabs` إلا ما يحمل `link`. وإذا لم يحمل أي تبويب `link`، يُعامَل العنصر على أنه عنصر تنقل عادي.

## الشريط الجانبي الأصلي

عندما لا يوجد مجلد لغة ولا `sidebar.items`، تقرأ السمة `themeConfig.sidebar` الخاص بـ VitePress (في `.vitepress/config.mts`) وتحوّله إلى البنية نفسها. تُحفظ `icon` و`badge` و`tabs` في العناصر الأصلية، وتُضاف `base` الخاصة بالمجموعة إلى بداية روابط عناصرها الفرعية وتبويباتها.

```ts
export default defineConfig({
  themeConfig: {
    sidebar: {
      "/theme/": [
        {
          text: "السمة",
          items: [
            { text: "التخطيط وشريط التطبيق", link: "/theme/layout", icon: "view_quilt" },
            { text: "توسيع السمة", link: "/theme/extending", badge: "توسيع" },
          ],
        },
      ],
    },
  },
});
```

## متغيرات CSS لشريط التبويب {#tab-bar-css-variables}

| المتغير | القيمة الافتراضية | التأثير |
| --- | --- | --- |
| `--akari-app-bar-tabs-gap` | `24px` | بعد الاستقرار في شريط التطبيق، المسافة بين شريط التبويب والعنوان، وبين شريط التبويب والأزرار على اليسار |
| `--akari-page-tabs-docked-max-width` | `none` | أقصى عرض لشريط التبويب بعد استقراره في شريط التطبيق؛ وعند ضبطه يتوسط شريط التبويب المساحة الفارغة |

## useSidebar

```ts
import { useSidebar } from "@theme";

const { items, prevNext, tabGroup, isActive, hasActive } = useSidebar();
```

| القيمة المُرجعة | النوع | الوصف |
| --- | --- | --- |
| `items` | `ComputedRef<AkariSidebarItem[]>` | شجرة التنقل للصفحة الحالية |
| `prevNext` | `ComputedRef<{ prev?, next? }>` | الصفحة السابقة والصفحة التالية ضمن مجموعة الصفحات المتوازية للصفحة الحالية؛ وهما غير موجودتين عند طرفَي المجموعة ولا خارج أي مجموعة |
| `tabGroup` | `ComputedRef<AkariSidebarItem \| undefined>` | مجموعة الصفحات المتوازية التي تنتمي إليها الصفحة الحالية |
| `isActive(link)` | `(link?: string) => boolean` | ما إذا كان هذا العنوان هو الصفحة الحالية |
| `hasActive(item)` | `(item: AkariSidebarItem) => boolean` | ما إذا كان هذا العنصر، أو أحد عناصره الفرعية أو تبويباته، هو الصفحة الحالية |

لا تستدعِها إلا من المكوّنات الموجودة داخل التخطيط.

## الأيقونات

يجب تسجيل الأيقونات المستخدمة في التنقل أولًا في `docs/.vitepress/theme/icons.ts`. راجع [استخدام الأيقونات](/ar-SA/styles/icons/using). الأيقونات غير المسجّلة تظهر فارغة.
