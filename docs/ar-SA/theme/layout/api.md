# التخطيط وشريط التطبيق: API

## appBar

| الحقل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `title` | `string` | `title` الموقع | اسم الموقع في شريط التطبيق |
| `version` | `string` | لا شيء | تسمية الإصدار بجانب الاسم، مثل `v1.0.0` |
| `logo` | `string` | قيمة `logo` في التهيئة | صورة العلامة التجارية؛ تُضاف `base` تلقائيًا إلى مسارات الموقع |
| `showSidebarToggle` | `boolean` | `true` | ما إذا كان يُعرض زر القائمة الذي يفتح درج التنقل على الشاشات الضيقة |
| `showSettingsToggle` | `boolean` | `true` | ما إذا كان يُعرض زر الإعدادات؛ ويكون مخفيًا دائمًا عندما تكون `settings.enabled` على `false` |
| `socialLinks` | `AkariSocialLink[]` | `[]` | روابط اجتماعية، تُفتح في علامة تبويب جديدة |

حقول `AkariSocialLink`:

| الحقل | النوع | الوصف |
| --- | --- | --- |
| `icon` | `string` | `github` و`npm` يعرضان شعارين مدمجين؛ وأي قيمة أخرى تُستخدم اسمًا لأيقونة m3e مسجّلة |
| `link` | `string` | الرابط |
| `label` | `string` | الاسم الميسّر (accessible name) للزر ونص التلميح، وهو أيضًا نصه في قائمة «المزيد» |

## toc

| الحقل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | ما إذا كان يُعرض جدول المحتويات (جدول المحتويات على اليسار وزر جدول المحتويات على الشاشات الضيقة) |
| `maxDepth` | `number` | `3` | يسرد من `h2` حتى `h{maxDepth}`؛ وتُحصر القيمة بين 1 و6 |
| `overline` | `string` | بحسب اللغة؛ «في هذه الصفحة» | العنوان الصغير في أعلى جدول المحتويات، والاسم الميسّر لتنقل جدول المحتويات |

لإيقاف جدول المحتويات في صفحة واحدة، اكتب `toc: false` في بياناتها الأمامية (frontmatter). العناوين التي تحمل الخاصية `m3e-toc-ignore` لا تُدرج في جدول المحتويات.

## loadingBar

| الحقل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | ما إذا كان يُعرض شريط تقدّم في أعلى النافذة أثناء تحميل الصفحة |

## footer

| الحقل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `message` | `string` | بحسب اللغة | النص أسفل الشعار واسم الموقع في التذييل |
| `copyright` | `string` | `""` | إشعار حقوق النشر في أسفل التذييل؛ لا يُعرض إذا كان فارغًا |
| `showPrevNext` | `boolean` | `true` | ما إذا كانت تُعرض بطاقتا الصفحة السابقة والصفحة التالية في المجموعة في نهاية محتوى الصفحات المتوازية |
| `links` | `AkariFooterLinkGroup[] \| false` | من التنقل | أعمدة الروابط في التذييل؛ افتراضيًا أول أربع فئات من التنقل، بحد أقصى ستة عناصر في كل عمود؛ و`false` يخفيها |

```ts
footer: {
  links: [
    {
      title: "الموارد",
      items: [
        { text: "GitHub", link: "https://github.com/OasisAkari/vitepress-theme-akari-docs" },
        { text: "سجل التغييرات", link: "/changelog" },
      ],
    },
  ],
},
```

تُفتح الروابط الخارجية في علامة تبويب جديدة. وتصبح مجموعة الصفحات المتوازية عنصرًا واحدًا في أعمدة الروابط.

## متغيرات CSS {#css-variables}

أعِد تعريفها في أنماط موقعك، على `:root` مثلًا:

| المتغير | القيمة الافتراضية | الغرض |
| --- | --- | --- |
| `--akari-doc-radius` | `28px` | نصف قطر زوايا سطح المستند وسطح التذييل |
| `--akari-doc-padding` | `32px` | حشوة الأسطح، والفجوة بين المحتوى وجدول المحتويات |
| `--akari-doc-top-space` | `32px` | المسافة بين سطح المستند وشريط التطبيق |
| `--akari-doc-max-width` | `1280px` | أقصى عرض للمحتوى وجدول المحتويات داخل السطح؛ ويستخدم محتوى التذييل العرض نفسه |
| `--akari-doc-text-measure` | `760px` | أقصى طول للسطر في الفقرات والقوائم والاقتباسات وصناديق التنبيه |
| `--akari-doc-text-offset` | `22px` | مقدار إزاحة الفقرات نسبةً إلى العناوين |
| `--akari-doc-toc-offset` | `128px` | المسافة أسفل شريط التطبيق التي يلتصق عندها جدول المحتويات |
| `--akari-toc-width` | `208px` | عرض جدول المحتويات |
| `--akari-doc-gap` | `16px` | المسافة بين العنوان وشريط التطبيق بعد الانتقال إلى مرساة |
| `--akari-doc-surface-color` | `--md-sys-color-surface` | لون خلفية سطح المستند وسطح التذييل؛ اضبطه داخل `m3e-theme` (على `.akari-main` مثلًا) لكي تُحَلّ رموز الألوان |
| `--akari-doc-divider-strength` | `30%` | شدة فاصل شريط التنقل وشدة إطار السطح بعد التمرير |
| `--akari-wavy-divider-color` | `--md-sys-color-outline-variant` | لون الفاصل المتموّج فوق التذييل |
| `--akari-doc-app-bar-height` | `64px` | ارتفاع شريط التطبيق؛ للقراءة فقط، ويُستخدم لحساب المواضع الملتصقة |
| `--akari-doc-rail-width` | `96px` | عرض شريط التنقل؛ للقراءة فقط |
| `--akari-loading-bar-height` | `4px` | ارتفاع شريط التحميل |
| `--akari-loading-bar-color` | `--md-sys-color-primary` | لون شريط التحميل |

```css
:root {
  --akari-doc-radius: 24px;
  --akari-doc-max-width: 1440px;
}

.akari-main {
  --akari-doc-surface-color: var(--md-sys-color-surface-container-lowest);
}
```

## حالة الصفحة

| العلامة | المكان | المعنى |
| --- | --- | --- |
| `data-akari-ready` | `html` | انتهى تسجيل مكوّنات m3e |
| `data-akari-scrolled` | `html` | مرّ سطح المستند أسفل شريط التطبيق عند التمرير |
| `akari-tabs-pinned` | اسم صنف على `html` | شريط التبويب للصفحات المتوازية يبقى أسفل شريط التطبيق |
| `data-akari-page-title` | عنصر | عنوان الصفحة الذي يتبعه تبديل العنوان في شريط التطبيق؛ افتراضيًا `h1` في المحتوى أو العنوان في قسم الواجهة |

| معرّف العنصر | المحتوى |
| --- | --- |
| `akari-doc-content` | حاوية المحتوى، التي يقرأ منها جدول المحتويات عناوينه؛ وهي `AKARI_CONTENT_ID` المُصدَّرة |
| `akari-sidebar` | درج التنقل على الأجهزة المحمولة؛ `AKARI_SIDEBAR_ID` |
| `akari-settings` | لوحة الإعدادات؛ `AKARI_SETTINGS_ID` |

## استبدال المكوّنات

يمكنك استبدال شريط التطبيق، والتنقل على سطح المكتب، والدرج على الأجهزة المحمولة، وقسم الواجهة، وجدول المحتويات، وبطاقات التنقل بين الصفحات، والتذييل، وحاوية المحتوى؛ راجع [توسيع السمة](/ar-SA/theme/extending/api#provideakaricomponents).
