# البحث

يقع البحث على يسار شريط التطبيق. على الشاشات العريضة يكون مربع بحث فيه نص توضيحي وتلميح للاختصار؛ وعلى الشاشات الضيقة يتقلص إلى زر دائري. انقر عليه أو اضغط `⌘K` (`Ctrl K` على Windows وLinux)، فيتمدد مربع البحث إلى لوحة البحث.

## الاستخدام

| المفتاح | الإجراء |
| --- | --- |
| `⌘K` / `Ctrl K` | فتح البحث في أي صفحة |
| `↑` / `↓` | التنقل بين النتائج |
| `Enter` | فتح النتيجة الحالية |
| `Esc` | إغلاق البحث |

تُسرد النتائج بحسب الصفحة والقسم، ولكل منها مقتطف من الموضع المطابق. فتح نتيجة تخص قسمًا ينقلك بالتمرير إلى عنوانه. وفي الموقع متعدد اللغات، لا تُعاد إلا صفحات اللغة الحالية.

## البحث العائم

ضع `<SearchDock>` حيث يجب أن يهبط حقل البحث. لا يحجز الوسم سوى إطار؛ ويغادر الحقل الفعلي شريط التطبيق ويقيس الإطار ويبقى فيه ما دامت الصفحة مفتوحة.

```md
# الدليل

<SearchDock variant="hero" align="center" placeholder="ابحث في الدليل" />
```

| الخاصية | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `placeholder` | `string` | `search.placeholder` | النص التوضيحي عند الإرساء هنا |
| `variant` | `"bar" \| "pill" \| "icon" \| "hero"` | `"bar"` | مظهر الحقل |
| `align` | `"start" \| "center" \| "end"` | `"start"` | موضع الأيقونة والنص واختصار لوحة المفاتيح |
| `width` | `string \| number` | عرض المظهر | طول CSS أو عرض بالبكسل للإطار المحجوز |
| `height` | `string \| number` | ارتفاع المظهر | طول CSS أو ارتفاع بالبكسل للإطار المحجوز |
| `fill` | `boolean` | `false` | ملء الإطار الأب بدل الحجم الطبيعي للمظهر |
| `immersive` | `boolean` | `false` | الكتابة والبحث مباشرة داخل الحقل دون فتح مربع الحوار |
| `showShortcut` | `boolean` | `true` | إظهار تلميح الاختصار في الحقل المرسى |
| `background` | `string` | سطح النمط | لون CSS لسطح حقل البحث |
| `borderColor` | `string` | حدود النمط | لون CSS لحدود حقل البحث |
| `shadow` | `boolean` | `true` | الإبقاء على ظل الارتفاع؛ `false` يزيله |
| `elevation` | `number` | مستوى النمط | مستوى ارتفاع MD3 من 0 إلى 5؛ `0` يزيل الظل |
| `priority` | `number` | `0` | يتقدّم على وسوم الصفحة نفسها |

الوسم مسجّل عالميًا، لذا لا تحتاج الصفحة إلى استيراده. ضعه في تدفّق الصفحة حيث ينبغي أن يكون الحقل؛ ويحدّد التخطيط المحيط الموضع الدقيق.

فتح هذه الصفحة مباشرةً يضع الحقل في الإطار دون انتقال. وعند الانتقال إليها من صفحة أخرى يطير من شريط التطبيق أو من موضع الإرساء السابق؛ وعند الانتقال إلى صفحة بلا وسم يعود إلى الشريط ويتلاشى. تغيير خاصية يعيد تشكيل الحقل أو محاذاته في مكانه. وإذا كانت الصفحة تضم عدة وسوم، يفوز الأعلى `priority`، وعند التساوي يفوز أول وسم يُعرض.

أثناء إرساء الحقل، يستعيد عنوان شريط التطبيق والتبويبات المرساة المساحة التي تركها الحقل، وتُفتح هذه المساحة بسلاسة عند عودته. لا يستلم الوسم الحقل إلا إذا كان إطاره كاملًا داخل منطقة الصفحة وإطار العرض، وخاليًا من تداخل شريط التطبيق وشريط التبويبات. وإلا يبقى الحقل في الشريط ويطير لاحقًا عندما يجعل التمرير الوسم في منطقة خالية. أثناء الطيران، يتحرك الحقل مع الوسم عند التمرير بدل أن يتخلف عنه ويقفز في النهاية؛ وإذا أصبح الوسم صالحًا مجددًا أثناء العودة، يستدير الطيران من موضعه الحالي بدل أن يبدأ من جديد. وأثناء العودة يتحوّل الحقل إلى سطح الشريط وخطّه وحشوه أثناء الطيران، لا عند الهبوط. تأتي المدد والمنحنيات من رموز حركة MD3 في السمة، فتتبع إعداد «قياسي / تعبيري» وتحترم `prefers-reduced-motion`.

راجع [العرض الحي](/ar-SA/theme/search/dock) و[API](/ar-SA/theme/search/api#searchdock) لكل الخصائص.

## الفهرس المحلي

لا تحتاج افتراضيًا إلى أي خدمة بحث خلفية. تستخدم السمة الفهرس الذي يبنيه البحث المحلي في VitePress، فهرسًا واحدًا لكل لغة، ولا يُنزَّل إلا عند أول بحث بتلك اللغة. تُقسَّم الصفحات إلى أقسام عند عناوينها، ويتولى [MiniSearch](https://lucaong.github.io/minisearch/) المطابقة: تُقسَّم الصينية واليابانية إلى كلمات، ويمكن كتابة جزء من الكلمة فقط، وقد يحتوي خطأً أو خطأين في الكلمات الأطول. وأثناء تشغيل خادم التطوير يتبع الفهرس تعديلاتك.

## استخدام بحث آخر

عندما تحتاج إلى البحث الدلالي أو محتوى من خارج الموقع، انتقل إلى نقطة نهاية HTTP أو دالة JS خاصة بك:

```ts
// docs/config.ts
search: {
  backend: { type: "http", endpoint: "/api/docs/search" },
},
```

راجع [API](/ar-SA/theme/search/api) لمعرفة كيفية كتابة خدمة بحث وصيغة النتائج، و[التفاصيل](/ar-SA/theme/search/details) لحركة اللوحة وكيفية بناء الفهرس وترتيب نتائجه.
