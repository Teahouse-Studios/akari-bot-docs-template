# معاينة الصور

يغلّف `AkariImagePreview` صورة داخل مصغّرة تُفتح بالنقر. تمتلئ بها منطقة المحتوى، ويمكن تكبيرها وتدويرها وتحريكها، ولوحة المفاتيح تقوم بالعمل نفسه.

## الاستخدام

<AkariImagePreview src="/hero/theme-hero.svg" alt="مظهر السمة" label="عرض مظهر السمة">
  <img src="/hero/theme-hero.svg" alt="مظهر السمة" width="360" />
</AkariImagePreview>

```html
<AkariImagePreview src="/hero/theme-hero.svg" alt="مظهر السمة" label="عرض مظهر السمة">
  <img src="/hero/theme-hero.svg" alt="مظهر السمة" width="360" />
</AkariImagePreview>
```

الفتحة الافتراضية هي المصغّرة نفسها. إن حُذفت، يرسم المكوّن عنصر `<img>` بنفسه، وإن مُرّرت، استُخدم تنسيقك كما هو واكتفى المكوّن بلفّه في زر.

الخصائص والفتحات وأصناف CSS ودوال الهندسة المصدَّرة موجودة في تبويب **API**.

## لوحة المفاتيح

| المفتاح | الأثر |
| --- | --- |
| `Esc` | إغلاق المعاينة |
| `+`، `=` | تكبير درجة واحدة |
| `-`، `_` | تصغير درجة واحدة |
| `0` | إعادة العرض إلى حالته |
| `r` | تدوير 90° باتجاه عقارب الساعة |
| `Shift` + `r` | تدوير 90° عكس عقارب الساعة |

يتراوح التكبير بين 50% و400%، بالعجلة أو بالنقر المزدوج أو بأزرار الشريط. والسحب ينقل الصورة، والنقر المزدوج على الصورة أو زر الإعادة يعيدها إلى عرض الفتح.

## الحركة والبدائل

عند الفتح تمتد الصورة من موضع مصغّرتها، وعند الإغلاق تنكمش إليه. وبعد تكبير العرض أو تدويره أو تحريكه يختفي الصندوق الواحد الذي تعود إليه، فتُتجاهل هذه الحركة ويبقى التلاشي وحده. وعند تفعيل «تقليل الحركة» لا يحدث سوى التلاشي.

إلى أن تُحمَّل الصورة المصغّرة يبقى الزر معطّلًا ويعرض كرة تحميل في الوسط. وتعرض المعاينة المفتوحة الكرة نفسها حتى تكتمل الصورة، ولا يُغلق النقر على الخلفية في تلك الأثناء، بينما يظل زر الإغلاق و`Esc` يعملان. ويأخذ الغطاءان نسبة الصورة ولونها المحسوبين وقت البناء، ثم يتلاشيان برموز المدة والتخفيف في MD3.

تُنقل طبقة المعاينة إلى `.akari-frame`، فلا يقتطعها تنسيق النص ولا `overflow`. ويُقفل تمرير الصفحة أثناء الفتح، ويعود التركيز إلى زر الفتح عند الإغلاق.
